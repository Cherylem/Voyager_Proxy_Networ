# Voyager Proxy Network - Установка для macOS

## Описание
Voyager Proxy Network - это VPN-клиент для безопасного и анонимного подключения к интернету.

## Системные требования
- macOS 11 или новее
- Доступ к интернету
- Права администратора для установки

## Установка

### Автоматическая установка (рекомендуется)

1. **Скачайте установочный пакет**:
    - Загрузите архив с приложением и файлом `Install.command`

2. **Распакуйте архив**:
    - Дважды кликните по скачанному архиву чтобы распаковать его

3. **Запустите установку**:
    - Откройте папку с распакованными файлами
    - Дважды кликните на файл `Install.command`

4. **Разрешите выполнение** (если потребуется):
    - Если появится предупреждение о безопасности, нажмите "OK"
    - В системных настройках "Защита и безопасность" разрешите запуск приложения

5. **Следуйте инструкциям**:
    - Введите пароль администратора когда потребуется
    - Дождитесь завершения установки

### Ручная установка

Если автоматическая установка не работает:

1. **Откройте Терминал**:
    - Нажмите `Cmd + Пробел`, введите "Терминал" и нажмите Enter

2. **Перейдите в папку с файлами**:
   cd /путь/к/папке/с/файлами

3. **Дайте права на выполнение (введие в терминал)**:
   - `chmod +x Install.command`

4. **Запустите установку**:
   - `./Install.command`
