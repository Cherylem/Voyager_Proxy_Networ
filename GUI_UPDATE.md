# ✨ Добавлены две новые кнопки в GUI

## 📥 Кнопка "Импорт" (верхний левый угол)

**Функциональность:**
- Открывает диалоговое окно для импорта конфигурации по ссылке
- Пользователь может вставить ссылку на конфигурацию
- Кнопки "Импортировать" и "Отмена"

**Расположение:** Верхний левый угол главного окна

**Код:** `ui/components.go` - метод `showImportConfigDialog()`

---

## ✅ Кнопка "Whitelist" (верхний левый угол)

**Функциональность:**
- Открывает окно управления белым списком сайтов
- Позволяет добавлять сайты, которые будут открываться **напрямую** (без VPN)
- Все остальные сайты работают через VPN
- Сохраняет список в файл `whitelist.json`

**Возможности:**
- ➕ Добавлять новые URL сайтов в список
- 🗑️ Удалять URL со список
- 💾 Сохранять изменения
- 📋 Просмотр всех добавленных сайтов

**Расположение:** Верхний левый угол главного окна

**Код:** `ui/components.go` - методы:
- `showWhitelistDialog()` - отображение диалога
- `loadWhitelist()` - загрузка whitelist из файла
- `saveWhitelist()` - сохранение whitelist в файл

## 🚀 Использование

### Импорт конфигурации:
1. Нажмите кнопку "📥 Импорт" в верхнем левом углу
2. Вставьте ссылку на конфигурацию
3. Нажмите "Импортировать"

### Управление Whitelist:
1. Нажмите кнопку "✅ Whitelist" в верхнем левом углу
2. Введите URL сайта в поле и нажмите "➕ Добавить сайт"
3. Повторяйте для всех нужных сайтов
4. Нажмите "💾 Сохранить" для сохранения изменений
